# AI content for Azure

## Export-RgTemplates.ps1

Use this to dump all resource templates in a resource group to files.

Open the folder in VSCode or another editor that has AI agent capabilities and have AI troubleshoot your Azure resources.

Ex. "Find the reason that my web site http://contoso.com is not available through the xyz Application Gateway. Use any tools available locally like nslookup, ping, Test-NetConnection, etc."
